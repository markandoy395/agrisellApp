# Accomplishment report rules

These preferences were recovered on October 5, 2026 from earlier report
conversations. This file makes them easy to find; it is not the original saved
rules file.

## Recovered preferences

- Use the existing monthly GAA accomplishment reports as the format reference.
- Include working days only, exclude Saturdays and Sundays, and arrange entries
  chronologically with correct dates and day names.
- Base activities on existing, implemented AgriSell features. Inspect the project
  before writing; do not invent features or claim unsupported test results.
- Keep each daily entry brief, clear, professional, and specific.
- Describe selected incremental improvements. The project continues through
  December, so do not describe the whole application as completed in one day
  or exhaustively list every feature in a monthly report.
- Avoid repetitive entries unless a task realistically continues over several days.
- Omit screenshots and the documentation section from monthly accomplishment
  reports.
- Save a professionally formatted Word document with consistent typography,
  margins, table borders, and bold headers. Keep table rows together across pages.
- Retain the employee name, position, and signature format of the monthly reference.
